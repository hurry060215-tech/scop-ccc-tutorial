Cell-Cell Communication Analysis

本页整理 scop 中与细胞通讯相关的函数、参数、结果结构和可视化形式。 内容以功能说明和代码示例为主，不限定固定分析路线。图谱部分使用 scop 自己的 CCCHeatmap()、CCCNetworkPlot()、CCCStatPlot() 生成；依赖特定后端对象的图会单独标注限制。

基本定义：细胞通讯分析利用细胞群表达矩阵和 ligand-receptor 先验数据库， 推断可能存在的细胞群间信号关系。结果通常表示候选机制或优先级，不等同于因果证明。

核心概念

细胞身份group.by 定义 sender 和 receiver，可以是细胞类型、状态、空间区域或实验分组。
L-R 事件一条记录通常包含 sender、receiver、ligand、receptor、pathway、score 和 p-value/rank。
聚合层级aggregation 面向细胞对或通路汇总；interaction 面向单个 L-R 对。
方法差异不同后端使用不同数据库、统计检验、聚合方式或 ligand-target 先验。
解释边界通讯结果依赖表达和先验库，需要结合表达分布、样本设计、空间邻近或实验验证。
问题类型相关函数常用图结果解释
细胞对层面的通讯强度RunLIANA(), RunCellChat()heatmap, circle, scatter关注 sender/receiver 组合、入边、出边和聚合 score。
L-R 对层面的候选关系RunLIANA(), RunCellphoneDB()dot, bubble_lr, bar检查 ligand 在 sender 中的表达和 receptor 在 receiver 中的表达。
信号通路层面的网络RunCellChat(), RunLIANA()pathway, pathway_bubble, lr_contribution通路汇总用于描述同类 L-R 对的总体模式。
条件或样本间差异RunCellChat(), RunMultiNichenetr()comparison, diff_heatmap, diff_network, ranknet解释时需要区分细胞数变化、表达变化和样本重复。
receiver 基因程序的上游 ligandRunNichenetr(), RunMultiNichenetr()ligand_target, gene将候选 ligand 与 receiver target genes 的先验调控关系联系起来。

函数参考与代码示例

本节按函数分别说明输入、输出和生物学含义。示例代码可以独立引用，具体组合取决于数据类型、实验设计和需要回答的问题。

group.by 与数据结构

多数 CCC 函数需要一个 Seurat 对象和一个细胞分组列。group.by 中的类别会被解释为 sender 和 receiver。 该列可以来自细胞类型注释、状态分型、空间区域或实验分组。

  • 生物学含义：把单个细胞归入可解释的群体，例如 beta cell、macrophage、ductal cell。
  • 质量控制：检查每个类别的细胞数、marker 表达、样本来源和条件分布。
关键参数
group.bymetadata 中定义 sender/receiver 类别的列；通常使用经过校正的细胞类型或状态标签。
assay/layer表达矩阵来源；多数通讯方法使用 normalized data。
sample.by多样本方法中的 biological sample 列，不应使用细胞 barcode。
 
library(scop)
library(Seurat)

data("pancreas_sub", package = "scop")
srt <- pancreas_sub

stopifnot("CellType" %in% colnames(srt@meta.data))
srt$CellType <- factor(srt$CellType)
table(srt$CellType)

# 可视化检查注释和样本分布
DimPlot(srt, group.by = "CellType", label = TRUE)

RunscOMM(): 细胞标签预测

RunscOMM() 执行 reference-to-query 标签预测。它不计算 ligand-receptor 通讯， 但可用于生成或校正后续 CCC 分析所需的细胞分组列。

  • 生物学问题：query 细胞与 reference 中哪些细胞类型最接近？罕见类别的识别情况如何？
  • 结果用途：预测标签会写入 metadata，可作为 RunLIANA()、RunCellChat() 的 group.by。
关键参数
reference带有参考标签的 Seurat 对象。
reference_label参考对象中的标签列，例如 CellType。
features用于分类的基因；为空时由函数自动选择。
prediction_prefix预测列名前缀，避免覆盖已有 metadata。
evaluate/truth_colquery 有真实标签时评估准确率和 rare recall。
scomm_epochs神经网络训练轮数；运行时间和模型稳定性会随该值变化。
 
query <- RunscOMM(
  srt = query,
  reference = reference,
  reference_assay = "RNA",
  query_assay = "RNA",
  reference_label = "CellType",
  prediction_prefix = "predicted_",
  scomm_epochs = 10
)

table(query$predicted_CellType)
query$CellType <- query$predicted_CellType

RunLIANA(): 多方法 L-R 推断

RunLIANA() 调用 LIANA 的多方法框架，将不同 L-R 评分策略整理为统一长表。 结果可用于细胞对、通路和单个 ligand-receptor 层面的可视化。

  • 生物学问题：哪些细胞群组合具有较高通讯分数？哪些 ligand-receptor 对在多种证据下排名靠前？
  • 相关图：heatmap、circle、dot、bar、pathway_summary。
关键参数
methodLIANA 内部评分方法；natmi/connectome/logfc/sca/cellphonedb 使用不同的表达、特异性和排序信息。
resourceL-R 数据库资源；Consensus 使用 LIANA 的共识资源。
min_cells细胞群参与分析所需的最低细胞数。
return_all是否返回全部候选交互；结果规模和噪声会随之增加。
...传给 LIANA 后端的高级参数。
 
srt <- RunLIANA(
  srt,
  group.by = "CellType",
  method = c("natmi", "connectome", "logfc", "sca", "cellphonedb"),
  resource = "Consensus",
  min_cells = 5,
  return_all = FALSE
)

CCCHeatmap(srt, method = "LIANA",
  plot_type = "heatmap", display_by = "aggregation")
CCCHeatmap(srt, method = "LIANA",
  plot_type = "dot", display_by = "interaction", top_n = 30)

RunCellphoneDB(): CellPhoneDB v5 分析

RunCellphoneDB() 调用 CellPhoneDB v5。统计模式下会通过置换细胞标签评估 ligand-receptor 组合在指定 sender/receiver 中是否具有显著性。

  • 生物学问题：某个 sender-receiver 组合里的 L-R 对是否具有统计支持？
  • 结果解释：score 描述表达支持，pvalue 来自置换检验。
关键参数
methodstatistical_analysis 做置换检验；analysis 不做置换；degs_analysis 结合 DEG。
convert_to_human小鼠数据接 CellPhoneDB 时通常设 TRUE，转换到人类同源基因。
threshold某基因在细胞群内表达细胞比例的下限。
pvalue显著性阈值。
iterations置换次数；增加该值通常会增加运行时间。
microenvs限制哪些细胞群可互相通讯，空间/组织区域分析很有用。
cores并行核数，影响运行速度。
 
srt <- RunCellphoneDB(
  srt,
  group.by = "CellType",
  species = "Mus_musculus",
  method = "statistical_analysis",
  convert_to_human = TRUE,
  threshold = 0.1,
  pvalue = 0.05,
  iterations = 1000,
  cores = 4
)

CCCHeatmap(srt, method = "CellphoneDB",
  plot_type = "bubble_lr", display_by = "interaction",
  pairLR.use = c("Jag1-Notch1", "Wnt5a-Fzd2"))

RunCellChat(): 通路网络和细胞角色

RunCellChat() 将 ligand-receptor 关系聚合到 signaling pathway，并提供网络强度、 细胞角色、中心性和条件比较相关结果。

  • 生物学问题：WNT、NOTCH、CXCL 等通路主要从哪里发出，流向哪里？处理组和对照组网络是否改变？
  • 相关图：circle、pathway、lr_contribution、role_scatter、ranknet。
关键参数
species选择 CellChat 数据库物种：人、小鼠或斑马鱼。
split.by按某个 metadata 列拆分对象后分别分析。
annotation_selected只保留指定细胞类型，适合聚焦某个生态位。
group_column/group_cmp条件比较设计，例如 treated vs control。
threshCellChat 通讯显著性过滤阈值。
min.cells细胞群最低细胞数，太小的群会被排除。
 
srt <- RunCellChat(
  srt,
  group.by = "CellType",
  species = "Mus_musculus",
  min.cells = 10,
  thresh = 0.05
)

CCCNetworkPlot(srt, method = "CellChat",
  plot_type = "circle", display_by = "aggregation")
CCCStatPlot(srt, method = "CellChat",
  plot_type = "lr_contribution", signaling = "NOTCH")

RunNichenetr(): receiver 基因程序与候选 ligand

RunNichenetr() 将 sender 中表达的 ligand、ligand-receptor 关系和 ligand-target 先验连接起来，用于解释 receiver 细胞中的目标基因集合。

  • 生物学问题：某个接收细胞状态改变，可能由哪些外源 ligand 驱动？
  • 相关图：ligand_target、bar、dot。
关键参数
receiver需要解释目标基因集合的接收细胞群。
sender候选发送细胞群；"all" 表示全部非 receiver 群。
condition.by/condition_oi/condition_reference定义 receiver 中的差异表达背景。
modeaggregate 使用条件差异；aggregate_cluster_de 使用 cluster 差异；custom 使用自定义目标基因集。
geneset自定义 receiver target genes，例如 DEG 或通路基因。
top_n_ligands/top_n_targets控制优先展示多少 ligand 和 target。
lr_network/ligand_target_matrix传入自定义 NicheNet 先验模型。
 
geneset_oi <- c("Ins1", "Ins2", "Gcg", "Pdx1", "Mafa")

srt <- RunNichenetr(
  srt,
  group.by = "CellType",
  receiver = "Endocrine",
  sender = "all",
  mode = "custom",
  geneset = geneset_oi,
  background_expressed_genes = rownames(srt),
  species = "Mus_musculus",
  top_n_ligands = 30,
  top_n_targets = 200
)

CCCHeatmap(srt, method = "Nichenetr",
  plot_type = "ligand_target", top_n = 30)

RunMultiNichenetr(): 多样本、多条件 NicheNet

RunMultiNichenetr() 扩展 NicheNet 到多样本、多条件设计， 将 sample 层面的重复、条件差异和 receiver target genes 纳入候选交互排序。

  • 生物学问题：疾病组相对对照组，哪些 sender-receiver-ligand-target 轴稳定改变？
  • 结果解释：关注跨样本一致性、cell type 特异性和 receiver target genes 支持。
关键参数
sample.by真实 biological sample ID，是多样本统计的核心变量。
condition.by实验条件列，例如 disease/control。
condition_oi/reference指定关注条件和参考条件。
receiver_celltypes重点解释哪些接收细胞类型。
sender_celltypes候选发送细胞；为空时使用可用细胞群。
batches/covariates批次和协变量，避免把技术差异误读成通讯变化。
fraction_cutoff/min_cells过滤低表达或低细胞数的 sample-celltype 组合。
 
srt <- RunMultiNichenetr(
  srt,
  group.by = "CellType",
  sample.by = "sample_id",
  condition.by = "condition",
  condition_oi = "treated",
  condition_reference = "control",
  receiver_celltypes = "Endocrine",
  sender_celltypes = c("Ductal", "Pre-endocrine"),
  species = "Mus_musculus",
  min_cells = 10,
  empirical_pval = TRUE,
  top_n_interactions = 250
)

CCCHeatmap(srt, method = "MultiNichenetr",
  plot_type = "ligand_target")
统一出口：ccc_to_liana() 用于把不同后端转成 LIANA-like 长表； ccc_to_adata() 用于和 OmicVerse communication AnnData 互通。二者主要承担格式转换和跨生态互操作。

LIANA 深入说明

LIANA 是一个整合型 ligand-receptor 分析框架。它可以调用多种推断方法，并使用统一格式返回 sender、receiver、ligand、receptor、score、rank 和资源信息。scop::RunLIANA() 在 R/Seurat 对象中封装该流程，并将结果写入 srt@tools[["LIANA"]]。

整合框架

LIANA 可整合表达强度、细胞群特异性、rank、统计显著性和数据库资源。不同方法产生的列含义不同，解释时需要区分 score、rank 和 p-value。

统一输出

scop 会把 LIANA 结果整理为 long_table、pair_table 和 liana_table。这些表可以直接供 CCC* 绘图函数使用。

srt <- RunLIANA(
  srt,
  group.by = "CellType",
  method = c("natmi", "connectome", "logfc", "sca", "cellphonedb"),
  resource = "Consensus",
  min_cells = 5,
  return_all = FALSE
)
LIANA 参数含义备注
group.by定义 sender/receiver 的 metadata 列。应与研究问题对应，例如细胞类型、状态或空间区域。
method参与推断的 LIANA 内部方法。报告结果时应写清具体方法列表。
resource使用的 ligand-receptor 资源。Consensus 为常用资源；也可按研究对象指定其他资源。
min_cells细胞群参与分析所需的最低细胞数。影响小细胞群是否被纳入。
return_all是否返回全部候选交互。TRUE 会增加结果表规模。
...传给 liana::liana_wrap() 的高级参数。用于 LIANA 原生接口中的高级设置。
解释 LIANA 结果：heatmap/circle 适合展示细胞对层面的聚合关系； dot/bar 适合展示 L-R 对；pathway_summary 可用于通路层面的汇总。

参数字典

下表汇总多个 CCC 函数中反复出现的参数，便于在不同方法之间对照。

参数类别含义注意事项
srt输入对象Seurat 对象，包含表达矩阵和 metadata。通讯分析通常需要 normalized data。
group.by细胞分组定义 sender 和 receiver 的 metadata 列。分组错误会直接影响 sender/receiver 解释。
species数据库选择选择人、小鼠、斑马鱼等数据库或先验。物种不匹配会造成基因映射失败或结果减少。
assay, layer表达矩阵指定表达矩阵来源。CellPhoneDB 通常使用 normalized expression。
sender.use, receiver.use细胞过滤保留指定 sender 或 receiver。名称必须与 group.by 的水平一致。
ligand.use, receptor.use基因过滤保留指定 ligand 或 receptor。基因符号和大小写需要与表达矩阵一致。
signaling通路过滤按 pathway 过滤结果。不同后端的 pathway 命名可能不同。
pairLR.useL-R 过滤保留指定 L-R 对。格式可能是 Ligand-Receptor 或后端自带 interaction 名称。
thresh, pvalue阈值显著性或过滤阈值。阈值会影响保留的交互数量。
top_n显示控制控制图上显示多少条结果。该参数通常只影响绘图展示，不改变原始分析结果。
display_by展示层级aggregation 显示细胞对聚合结果，interaction 显示 L-R 对。应与图的解释层级一致。
condition.by, sample.by实验设计条件和样本层级。sample.by 应为 biological sample。

下面这些 plot_type 是 scop 接口的一部分，但需要特定后端结果或当前版本条件；不能用普通 LIANA 示例长表直接出图。

plot_type所属函数需要什么说明
matrix_dotCCCHeatmap()无接口已移除，请用 dot。
role_heatmap, role_network, role_network_marsileaCCCHeatmap() / CCCStatPlot()真实 CellChat 结果用于 CellChat pathway role centrality。
diff_heatmap, diff_network, ranknet, role_changeHeatmap/Network/StatCellChat 条件比较结果需要 RunCellChat(group_column=..., group_cmp=...) 成功运行。
diffusionCCCNetworkPlot()当前 R 后端限制当前 scop 返回提示：无直接 R backend。
geneCCCStatPlot()CellChat pathway gene 表达结构普通 LIANA 长表无法直接提供该图所需对象。

代码片段

下面是常用函数组合的独立代码片段，可按数据和问题选用。

# LIANA: 多方法 L-R 推断
srt <- RunLIANA(srt, group.by = "CellType", resource = "Consensus", min_cells = 5)

# 细胞对聚合结果
CCCHeatmap(srt, method = "LIANA", plot_type = "heatmap", display_by = "aggregation")
CCCNetworkPlot(srt, method = "LIANA", plot_type = "circle", display_by = "aggregation")

# L-R 对结果
CCCHeatmap(srt, method = "LIANA", plot_type = "dot", display_by = "interaction", top_n = 30)
CCCStatPlot(srt, method = "LIANA", plot_type = "bar", display_by = "interaction", top_n = 20)

# NicheNet: receiver target genes 与候选 ligand
srt <- RunNichenetr(
  srt,
  group.by = "CellType",
  receiver = "Endocrine",
  sender = "all",
  mode = "custom",
  geneset = geneset_oi,
  background_expressed_genes = rownames(srt),
  species = "Mus_musculus"
)
CCCHeatmap(srt, method = "Nichenetr", plot_type = "ligand_target")

排错

现象原因处理
结果为空细胞群太小、阈值太严、表达层错误检查 table(srt$CellType)，确认 normalized data，适当调低阈值。
CellPhoneDB 小鼠结果少未转 human ortholog设置 convert_to_human = TRUE。
图太密细胞群和 L-R 对太多用 top_n、sender.use、receiver.use、signaling 聚焦。
NicheNet 报错receiver、condition 或 geneset 逻辑不完整检查 receiver、目标基因集和条件字段。
CellChat 专属图不出缺少真实 CellChat 对象或版本不兼容检查 RunCellChat() 是否成功，以及 srt@tools[["CellChat"]] 是否有结果。
