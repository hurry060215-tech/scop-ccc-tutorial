# scop Cell-Cell Communication Analysis Tutorial

Standalone HTML tutorial for the cell-cell communication analysis functions in `scop`.

Open `index.html` locally, or publish the repository with GitHub Pages.

## Covered functions

- `RunCellChat()`
- `RunCellphoneDB()`
- `RunLIANA()`
- `RunNichenetr()`
- `RunMultiNichenetr()`
- `RunscOMM()`
- `ccc_to_adata()`
- `ccc_to_liana()`
- `CCCHeatmap()`
- `CCCNetworkPlot()`
- `CCCStatPlot()`

## Structure

- `index.html`: full Chinese tutorial and function atlas.
- `assets/styles.css`: static page styling.
- `assets/figures/`: example communication plots generated from the local `scop` tutorial script.

## Notes

The example figures are teaching figures. They demonstrate how to read `scop` CCC plot outputs and should be replaced by user-generated plots in a real biological analysis.
